# Changelog

## 1.0.0

First public release.

- Clipboard history: text, rich text, images, files · search · ⌘1–9 paste · plain paste · pins · smart types with one-click actions (JSON pretty-print, URL open, color convert, case, trim…)
- Screenshots: instant capture shortcuts, on-device OCR (searchable, copy text), optional monthly folders
- The island: a Dynamic-Island-style surface over the notch — Home (Now Playing, agent, weather, up next), Clips, Shelf, Agents, Up Next, Prompter, Focus (Pomodoro)
- Claude Code agent monitor: permission requests appear in the notch; Allow / Deny from there
- Now Playing for Spotify, Apple Music, and YouTube Music / YouTube in Chromium browsers
- Shelf: drop files on the notch, drag them out anywhere
- Timers & Pomodoro with a countdown ring in the notch
- Calendar / reminders (Up Next) and weather, both opt-in
- Preferences: hotkeys, capture, screenshots, notch behaviour, agents
